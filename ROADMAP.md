# Roadmap

## Phase 1 — local scanner

- typed finding and rule contracts
- safe repository traversal
- secret-detection rule pack
- text and JSON CLI reporters
- offline test suite

## Phase 2 — policy engine

- insecure workflow and container checks
- severity thresholds and allowlists
- baseline files with expiring suppressions
- changed-line scanning

## Phase 3 — CI integration

- SARIF output
- reusable GitHub Actions workflow
- pull-request annotations
- documented exit-code contract

## Phase 4 — repository intelligence

- dependency advisory adapters
- trend snapshots
- repository-level risk summaries
- lightweight dashboard
